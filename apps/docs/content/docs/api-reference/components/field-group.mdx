# \<FieldGroup\>

Render a set of fields in a group.

Use it in [`renderFields`](/docs/api-reference/configuration/component-config#renderfieldsprops) and the [`fields` override](/docs/api-reference/overrides/fields) to create logical groupings.

<Example1 />

```tsx {6-13} copy
import { Puck, FieldGroup } from "@puckeditor/core";

export function Editor() {
  return (
    <Puck>
      <FieldGroup label="Appearance">
        <FieldGroup.Item>
          <input type="text" value="#000000" onChange={() => {}} />
        </FieldGroup.Item>
        <FieldGroup.Item>
          <input type="number" value="12" onChange={() => {}} />
        </FieldGroup.Item>
      </FieldGroup>
    </Puck>
  );
}
```

## Props

| Param                                 | Example                 | Type                  | Status |
| ------------------------------------- | ----------------------- | --------------------- | ------ |
| [`children`](#children)               | `children: <div />`     | ReactNode             | -      |
| [`collapsible`](#collapsible)         | `collapsible: false`    | Boolean               | -      |
| [`defaultExpanded`](#defaultexpanded) | `defaultExpanded: true` | Boolean               | -      |
| [`icon`](#icon)                       | `icon: <svg />`         | ReactNode             | -      |
| [`id`](#id)                           | `id: "appearance"`      | String                | -      |
| [`label`](#label)                     | `label: "Appearance"`   | String                | -      |
| [`variant`](#variant)                 | `variant: "card"`       | `"flush"` \| `"card"` | -      |

## Optional props

### `children`

The fields to render inside the group. Will likely contain [`<FieldGroup.Item>`](field-group-item) nodes. Nothing is rendered if there are no children, or only empty strings.

### `collapsible`

Let users show and hide the children by clicking the label. **Defaults to `true`**.

```tsx /collapsible/ copy
<FieldGroup label="Appearance" collapsible={false}>
  <FieldGroup.Item>
    <input type="text" value="#000000" onChange={() => {}} />
  </FieldGroup.Item>
</FieldGroup>
```

<Example2 />

### `defaultExpanded`

Expand the children by default. Only applies when [`collapsible`](#collapsible) is `true`. **Defaults to `false`**.

```tsx /defaultExpanded/ copy
<FieldGroup label="Appearance" defaultExpanded>
  <FieldGroup.Item>
    <input type="text" value="#000000" onChange={() => {}} />
  </FieldGroup.Item>
</FieldGroup>
```

<Example3 />

### `icon`

Render an icon before the label text. Puck uses [lucide-react](https://lucide.dev/guide/packages/lucide-react) internally.

### `id`

An optional ID for this group, used as the key in [`ui.expandedFieldGroups`](/docs/api-reference/data-model/app-state#uiexpandedfieldgroups). Use it to preserve the group's expanded state across remounts.

This prop has no effect outside `<Puck>`.

### `label`

The label for the group. Required unless [`collapsible`](#collapsible) is `false`.

### `variant`

The visual style of the group. **Defaults to `"flush"`**.

- `"flush"` (default): render the fields without a container. Nested groups are indented.
- `"card"`: render the fields inside a bordered container.
